📝 创建数据库操作流程
  1. 在 pigsty.yml 对应集群的 pg_databases 下声明库名，例如： 
    - name: mydb
  comment: "created via admin webui"
  2. 在「运维操作 → 创建库」填写 集群名 与 库名，确认执行 ./pgsql-db.yml -l <集群> -e dbname=<库名>。
  3. 未先在 pg_databases 声明会报 define database xxx in pg_databases first，属正常校验。
