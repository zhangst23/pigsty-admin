🛠 运维操作

📝 创建数据库操作流程
  1. 在 pigsty.yml 对应集群的 pg_databases 下声明库名，例如： 
    - name: mydb
  comment: "created via admin webui"
  2. 在「运维操作 → 创建库」填写 集群名 与 库名，确认执行 ./pgsql-db.yml -l <集群> -e dbname=<库名>。
  3. 未先在 pg_databases 声明会报 define database xxx in pg_databases first，属正常校验。

⌨ 命令操作

📋 常见命令（点击复制后粘贴到下方）
  • cd /root/pigsty && ansible-playbook pgsql-db.yml -l pg-meta
  • cd /root/pigsty && ansible-playbook pgsql-db.yml -l pg-meta -e dbname=pg1
  • cd /root/pigsty && ansible-playbook pgsql.yml -l pg-meta --check
  • pig pg list
  • pig pt list -f json
  • pig pb list
  • pig pg psql postgres -c "SELECT datname FROM pg_database WHERE NOT datistemplate;"
  • sudo systemctl status patroni

⚠️ 仅允许与 Pigsty 运维相关的命令；不支持管道 |、重定向 >、复合命令 && 及危险子串（rm/mv/cp/sudo/kill 等）。如需复合命令，请拆成单条执行。
